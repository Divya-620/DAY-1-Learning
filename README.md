Understanding how tables connect is the foundation of working with databases. Here's what I've been learning:
Keys
🔹 Primary Key: uniquely identifies each row in a table
🔹 Foreign Key: links one table to another by referencing its primary key
Checking the connection between two tables: 
          we have to check with drop and insert commands.
Joins🤝
🔹 INNER JOIN: only matching rows from both tables
🔹 LEFT JOIN: all rows from the left table, plus matches from the right
🔹 RIGHT JOIN: all rows from the right table, plus matches from the left.

No slicing, no built-ins. Just basic logic.
Approach
🔹 Placeholder: an empty string to build the result
🔹 Counter: starts at the last index and moves backward
🔹 Concatenation: add each character to the placeholder
and order is important.
